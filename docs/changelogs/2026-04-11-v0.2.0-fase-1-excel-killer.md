# Fase 1 — Excel Killer (v0.2.0)

**Released:** 2026-04-11

## Summary

Backend funcional para uso personal: replica el flujo de la hoja de Google que motivó el proyecto. Permite registrar juegos, llevar un backlog con ratio = puntuación / duración, crear listas curadas, vistas guardadas, importar juegos desde RAWG y consultar el shelf personal. Estructura final del módulo de tracking (`Backlog`, ex-`Playthrough`) y todo el sistema de filtros del backlog. Renombramos `Backlogr` a `Completr`.

## Highlights

- Módulo `backlog` (antes `playthroughs`) como fuente única del estado del usuario sobre un juego: `not_started`, `playing`, `completed`, `abandoned`.
- Ratio en backend con 2 decimales (`score / duration`) y `personalRatio` desde duración real.
- Vistas guardadas (`saved-filters`) con límite de 5 y congelamiento al bajar plan.
- Filtrado y ordenamiento completo del backlog: status múltiple, rangos de score/duration/rating, `no_finished_date`, sorts por title/ratio/personalRatio.
- Listas curadas con `scoreSource`/`durationSource` por lista, `ListItem` con scores congelados, `list-followers` para seguir listas públicas.
- Búsqueda de juegos con fallback a RAWG, `GameExternalId` para evitar duplicados, soporte para 3 resultados con detalle completo.
- `request.locals` como contenedor de datos validados (Express 5 hace `request.query` inmutable).

## Added

- **Backlog (`backlog/`):** modelo central con `status`, `score`, `duration`, `realDuration`, `userRating`, `startedAt`, `finishedAt`, `notes`, `isPublic`. Reemplaza a `UserGameStatus`.
- **Saved-filters (`saved-filters/`):** CRUD con límite de 5, error 402 al exceder, congelamiento al downgrade. Nested bajo `/users/me/saved-filters`.
- **Lists (`lists/`):** modelo con `scoreSource`/`durationSource` por lista, `backlogStatus` por item para el viewer, contador de seguidores.
- **List-items (`list-items/`):** CRUD vía `PUT /lists/:id/items` (array completo), endpoint `refresh-scores` para actualizar desde la fuente.
- **List-followers (`list-followers/`):** follow/unfollow con flag `isVisible` para ocultar del perfil público.
- **Wishlist + Favorites:** módulos independientes (no son listas). Wishlist apunta a `Backlog` (runs específicas), Favorites apunta a `Game`. Visibilidad por flag en `User`.
- **GameExternalId (`game-external-ids/`):** mapeo de juegos a IDs externos (RAWG) para detectar duplicados.
- **Búsqueda con RAWG fallback:** `GET /games/search` busca local, cae a RAWG si no encuentra, importa hasta 3 resultados con detalle completo, excluye DLCs.
- **Endpoints RAWG admin:** `/games/rawg-lookup` y `/games/rawg-detail/:rawgId` para re-scrape manual.
- **`request.locals` (Express 5):** declaration merging en `express.d.ts`, middlewares y controllers migrados.
- **Genres en game queries:** `findGamesByGenreCode`, genres incluidos en serializers de games y game-shelf.

## Changed

- **Rename `Playthrough` → `Backlog` en todo el código y docs.** Concepto: cada vez que el usuario quiere/inicia/reinicia un juego se crea un nuevo Backlog.
- **Rename `Backlogr` → `Completr` en todas las fuentes oficiales (`backlogr` → `completr` en `GameScore`/`GameTime`) y docs.**
- **Remoción de `UserGameStatus`:** el estado vive solo en `Backlog`.
- **Listas rediseñadas:** removido `basedOnId`/`isFork`, follow como bookmark social, listas no permiten valores custom de scores.
- **`coverUrl` → `backgroundUrl`** en todos los serializers (RAWG mapea a backgroundUrl).
- **`registerGame` en transacción** con validación previa de platforms y genres.
- **Status `not_started`** como default en Backlog.
- **PATCH /games/:id** permite actualizar título con regeneración de slug.
- **Hard delete** con CASCADE para admin, onDelete CASCADE en todas las asociaciones de Game.
- **Register endpoint restringido a admin** (Fase 1 es uso personal).
- **GET endpoints públicos** en `games`, `genres`, `platforms` (solo rate limit, sin auth).
- **`ScoreSource` como tabla** en vez de ENUM (FK STRING).
- **PC platform expandida** a múltiples stores en mapeo desde RAWG.
- **Fixes de timezone:** `startedAt`/`finishedAt`/`releaseAt` cambiados a `DATEONLY`.
- **`userRating` scale** cambiado de 1-10 a 0.5-5 (medios pasos).

## Fixed

- `coverUrl` → `backgroundUrl` consistencia en sub-serializers.
- Wildcard origin en CORS sin split a array.
- Description column de `VARCHAR(255)` → `TEXT`.
- Auth con `findUserByUsername` para check de username (no email).
- Routes pluralizados en `platforms` y `genres`, `GET /genres/:code/games` agregado.
- `realDuration` filter separado de `duration` en queries de backlog.
- Failures individuales de RAWG no rompen los resultados exitosos.

## Files of interest

- `src/backlog/` — módulo central de tracking.
- `src/lists/`, `src/list-items/`, `src/list-followers/` — sistema de listas curadas.
- `src/wishlist/`, `src/favorites/` — marcas personales ligeras.
- `src/saved-filters/` — vistas guardadas.
- `src/common/types/express.d.ts` — declaration merging de `request.locals`.
