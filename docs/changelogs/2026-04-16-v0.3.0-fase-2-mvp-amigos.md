# Fase 2 — MVP Amigos (v0.3.0)

**Released:** 2026-04-16

## Summary

Primer release multi-usuario. El producto deja de ser personal y se abre a 5-20 amigos cercanos. La fase trae todo lo social (seguir usuarios, feed de actividad, búsqueda de usuarios y listas, perfiles públicos enriquecidos), capa de moderación (`audit`, `game-reports`, panel de admin), reviews por backlog, refresh token con rotación y cookies HttpOnly, jobs asincrónicos (populate-rawg, ratings, durations) y migraciones formales con `sequelize-cli`.

## Highlights

- Social: follow/unfollow de usuarios, feed con actividades por tipo (`backlog_*`, `wishlist_added`, `list_followed`, `user_followed`, `list_created`, `game_reviewed`), búsqueda de usuarios y listas.
- Perfiles públicos enriquecidos: backlog totals, lists, favorites, wishlist, following-lists, follower counts.
- Reviews: módulo nuevo con `POST/GET` por usuario y por juego, integrado al feed con `game_reviewed`.
- Auth con refresh token y rotación, sesiones almacenadas en HttpOnly cookie.
- Audit log + game reports: panel de moderación para tracking de acciones administrativas y reportes de usuarios.
- Admin user management: `POST /admin/users` para crear, edición de rol/password.
- Jobs asincrónicos: `populate-rawg`, `calculate-ratings`, `calculate-durations` con status check y cancelación.
- Migraciones formales con `sequelize-cli` reemplazando `sequelize.sync`.

## Added

- **User-followers (`user-followers/`):** sistema completo de follow/unfollow con contadores en perfil.
- **Activity (`activity/`):** modelo con sub-models (`ActivityGame`, `ActivityList`, `ActivityUser`), feed con paginación, eventos `wishlist_added`, `shelf_added`, `user_followed`, `user_followed_by`, `list_followed`, `list_created`, `game_reviewed`, `backlog_*`.
- **Reviews (`reviews/`):** modelo, service, controller, routes con `POST/GET /games/:id/reviews` y `GET /users/:username/reviews`, integrado al feed.
- **Game reports (`game-reports/`):** módulo con create/list/update-status para reportes de usuarios.
- **Audit log (`audit/`):** modelo + endpoint admin-only para log de acciones.
- **Admin (`admin/`):** `POST /admin/users`, edición de usuario con role/password, lookup unfiltered para inactivos.
- **Jobs (`jobs/`):** modelo `Job`, endpoints admin para `populate-rawg`, `calculate-ratings`, `calculate-durations`. Soporta `limit` param y cancelación con status check por iteración. Umbral del 10% de usuarios para ratings/durations.
- **Search:** endpoints `/search/users` y `/search/lists`.
- **Refresh token:** rotación, almacenado en HttpOnly cookie, `deviceInfo` y `lastUsedAt` por sesión.
- **Pagination compartida:** `PaginationQuerySchema` con `limit`/`offset` reusable.
- **`isFeedPublic`** privacidad para el feed.
- **Roles ampliados:** `moderator` con permisos de reports y CRUD de catálogo (no delete de game).
- **List progress:** cálculo personal por usuario en list detail y en following-lists.
- **`local_only`** param en `/games/search` para excluir RAWG fallback.
- **Migraciones formales:** `sequelize-cli` con migration config + scripts (`migrate`, `migrate:undo`, `migrate:status`).

## Changed

- **Removed `sequelize.sync`:** todo el schema se maneja con migraciones.
- **Auth ampliada:** la mayoría de endpoints ahora requieren autenticación; los de perfil y colección quedan públicos para descubrimiento.
- **Profile self-view:** el usuario puede ver su propio perfil aunque sea privado.
- **Game-shelf, wishlist, favorites, following-lists** paginados con limit/offset/total.
- **Backlog:** búsqueda y paginación server-side.
- **Activity feed:** incluye actividades propias, eventos `list_created` al crear lista pública.
- **List followers:** endpoints separados `GET followers`, `GET following`, toggle de `isVisible`.
- **`acquiredAt`, `edition`, `notes`** del game-shelf pueden ser null en update.

## Fixed

- **Backlog `realDuration`** filtrado separado de `duration` con sus propios query params.
- **Activity:** incluido `backlog_not_started` para que el game target se cree.
- **DB migrations:** ENUMs y `TIMESTAMPTZ` correctos en migración inicial, claves de config renombradas para matchear `NODE_ENV`.

## Files of interest

- `src/user-followers/`, `src/activity/`, `src/reviews/` — capa social.
- `src/audit/`, `src/game-reports/`, `src/jobs/` — capa de moderación y mantenimiento.
- `src/auth/services/token.service.ts` — refresh token con rotación.
- `migrations/` — primeras migraciones formales con `sequelize-cli`.
