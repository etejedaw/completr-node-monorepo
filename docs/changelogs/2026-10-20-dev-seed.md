# Seed de datos para desarrollo

**Released:** 2026-10-20

## Summary

Una base local recién migrada quedaba vacía y había que cargar datos a mano para probar cualquier flujo. `npm run seed:dev` la llena con lo mínimo: dos usuarios, el catálogo base y un juego por cada caso del modal de añadir juego. Es idempotente y solo corre contra una base local en entorno `dev`.

## Added

- `apps/api/scripts/seed-dev.ts`: crea con `findOrCreate` dentro de una transacción:
    - usuarios `admin@completr.local` (admin) y `user@completr.local` (user);
    - plataformas PC, PlayStation 5, Nintendo Switch y Xbox Series X|S, y las fuentes de puntaje con su escala;
    - seis juegos: Astro Bot (todo autocompletado, una plataforma), Hades (varias plataformas), Balatro (sin puntajes), Celeste (sin duración), Tunic (sin puntajes ni duración) y Hollow Knight (sin plataformas);
    - tres entradas de backlog del usuario normal en `playing`, `completed` y `not_started`.
- Guard de entorno: se niega a correr si `NODE_ENV` no es `dev` o si `PG_HOST` no es local.
- Script `seed:dev` en `apps/api/package.json` (ts-node, lee `.env.dev.local` si existe) y alias en el `package.json` de la raíz.
- `README.md`: paso opcional "Cargar datos de prueba" con credenciales y datos que crea.
