# Fase 0 — Setup, frontend (v0.1.0)

**Released:** 2026-04-09

## Summary

Base técnica del frontend en Angular, en paralelo a `2026-04-04-v0.1.0-fase-0-setup.md` del backend. Deja listo el esqueleto de la app: configuración por entorno, modelos, autenticación con interceptores y guards, layout con rutas lazy para cada feature y PWA. Ninguna feature es funcional todavía; las rutas apuntan a componentes placeholder.

## Added

- Proyecto Angular con configuración por entorno (`environments/` y `fileReplacements` en `angular.json`).
- Interfaces de modelos del dominio.
- `core`: `AuthService`, `StorageService`, interceptores HTTP y guards.
- Layout y rutas lazy con componentes placeholder para todas las features.
- PWA: service worker, manifest e íconos.
