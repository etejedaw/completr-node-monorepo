# Changelogs

Un archivo por feature entregada. Cubre las dos apps del repo (`apps/api` y `apps/web`).

## Formato

- **Nombre del archivo:** `YYYY-MM-DD-<feature>.md`, en kebab-case. Las entregas de una fase incluyen la versión: `YYYY-MM-DD-vX.Y.Z-<feature>.md`.
- **Fechas:** `YYYY-MM-DD`. La fecha del nombre y la de `Released` son la del último commit del grupo.
- **Secciones obligatorias:** `Released`, `Summary` y `Commits`. `Highlights`, `Added`, `Changed`, `Removed`, `Fixed`, `Migration` y `Files of interest` solo si aplican.
- **Commits:** hash corto entre backticks y subject: `` `c892226` `` — `feat(backlog): add calendar view`.

Los changelogs no se reescriben: si algo cambia después, va en un changelog nuevo.
