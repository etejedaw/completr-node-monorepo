# Co-op runs

**Released:** 2026-06-25

## Summary

Nuevo módulo `coop-runs` que permite etiquetar amigos en runs de co-op multiplayer. Cada `Backlog` puede vincularse a un `CoopRun` que agrupa N entries de distintos users compartiendo la misma sesión. Tagear es auto-aceptado y reversible, con sync manual y selectivo de metadatos objetivos (`status`, `startedAt`, `finishedAt`, `realDuration`) entre miembros — datos personales (score, rating, notes, mood tags, progress notes) nunca se sincronizan. El sistema respeta la privacidad del taggeado: si su backlog es privado contra el tagger, se crea siempre una entry nueva (Opción C) sin tocar sus runs viejas.

## Highlights

- Modelo `CoopRuns(id, gameId)` + columna nullable `Backlogs.coopRunId` que vincula múltiples backlogs entre users.
- Auto-create con copia de `score` + `duration` del tagger cuando el target no tiene entry previa.
- Cuando el target es visible y tiene 2+ candidatas, el endpoint `GET .../coop/candidates` permite al frontend mostrar un picker; runs ya en otro coop quedan deshabilitadas.
- Sync con diff selectivo: el frontend muestra checkboxes por field con preview "mi valor → su valor".
- Auto-cleanup: si una CoopRun queda con 1 o 0 miembros, se borra y los backlogs se desvinculan. Job admin `POST /admin/jobs/cleanup-coop-runs` cubre el cleanup en lote.
- Nuevo tipo de actividad `coop_tagged` registrado en el feed al tagear.
- Restricción: solo podés tagear users a los que seguís.
